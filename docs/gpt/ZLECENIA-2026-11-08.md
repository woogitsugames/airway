# Zlecenia dla GPT — pakiet 2026-11-08 (po decyzji D-323)

12 samodzielnych zleceń (GPT-22…GPT-33) dla agenta kodującego z dostępem do repo (np. Codex). Wszystkie omijają prace,
które teraz robią agenci Claude (nowy globus NASA w `src/render/**`, nowy UI „UI-A” w `src/ui/**`, `public/fonts`,
`docs/styles/**`). Każde zlecenie = osobna gałąź i osobny szkic PR, kolejność dowolna, można puścić wszystkie równolegle.

## Jak używać
1. Wklej **wspólną preambułę** (niżej) i **jedno** zlecenie pod nią. Jedno zlecenie = jedna sesja GPT.
2. GPT: `git fetch origin dev && git switch -c gpt/NN-slug origin/dev`, praca, testy, **`git push -u origin gpt/NN-slug`**
   i otwarcie **szkicu PR do `dev`** (tytuł i opis po polsku). **Wszystko ma być wypchnięte na GitHub** (gałąź + PR),
   nic nie zostaje tylko lokalnie ani w ZIP-ie. Jeśli nie masz uprawnień do pushu: odeślij gałąź jako `git format-patch`
   i napisz to wprost w odpowiedzi — nie udawaj, że wypchnięto.
3. Nie scalaj niczego i nie pushuj do `dev` ani `main`. Scala koordynator (Claude) po przeglądzie.
4. Numery decyzji: kolejny wolny D-xx (dziś **D-327**; D-325 zajmuje render R1) — przy kolizji koordynator przenumeruje.
