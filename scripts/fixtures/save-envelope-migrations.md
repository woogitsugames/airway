# Save envelope migration fixtures

`save-envelope-v2.json`, `save-envelope-v3.json`, `save-envelope-v4.json` and `save-envelope-v6.json` were generated using the actual historical writer and simulation at commits `d68e63d`, `eeaeb16`, `de03441` and `0b6f1ba` respectively. They are newly generated test runs, not user saves: seed 0xA1A1, 120 ticks, savedAt 0. The versions exercise home region EUS, then weekly contract, demand surge and the old weather flag respectively. The v6 weather rules are deliberately refused by the current reader.

`save-envelope-v0-synthetic.json` is a reconstruction of the documented pre-checksum envelope using the simulation snapshot and journal in the existing `save-golden.json`; it is not evidence of a historical v0 writer. `save-envelope-v7.json` was generated by the current writer with EUS, contract, surge, class II and weather at the same seed and tick. Existing `save-golden*.json` and `eus-pre-v2-save.json` retain their existing provenance; the former are envelopes v1 with different simulation rules versions, while the latter is an envelope v5. These fixtures cover representative paths, not all possible game states, old rules versions, native storage implementations or upgrade combinations.
